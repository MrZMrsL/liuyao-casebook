# 六爻案例库 · 可视化看板（脱敏公开镜像）

断卦 → 复盘 → 提炼规则 → 进化。本仓库是本地 Markdown 案例库（唯一数据源）的脱敏公开镜像与可视化前端。

## 在线访问
GitHub Pages：`https://mrzmrsl.github.io/liuyao-casebook/`

## 结构
- `index.html` — 单页应用（看板 / 断卦流程 / 案例卡（全要素卦盘）/ 规则库 R1–R17 / 附录典籍）
- `assets/data.js` — **数据层：今后同步更新只改此文件**
- `appendix/*.md` — 方法论与工具书原文（页面运行时加载渲染）

## 同步流程（每次反馈/新案例后执行）
1. 本地 Markdown 库：备份 → 入库 → 复盘四件套 → 更新总索引看板
2. 脱敏转换（隐去占问编号、个人背景等可定位信息）
3. 更新 `assets/data.js`（与 appendix 若有修订）
4. push 到 main，Pages 约 1 分钟生效

## 脱敏规则
- 隐去占问编号（如"396"）、地理位置、可定位个人的背景细节
- 保留全部学术内容：卦盘、断语、复盘、规则
