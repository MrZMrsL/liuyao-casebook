# 通用断卦细则（跨分类适用 v1.0）

> 本文件是六步流程的补充细则，处理特殊卦形、录入规范与交叉验证。
> 与 SKILL.md 流程冲突时：流程框架以 skill 为准，取象细则以本文件与各分类案例库为准。

## 一、特殊卦形处理

### 1. 多爻发动（两爻及以上同动）
- 取**世爻之动**为第一信号；世不动则取**与用神关系最密切之动爻**
- 多动看"动爻链"：诸动爻化出之六亲若同向，则信号极强；若相背，以旺相者、临世应者为准
- 乱动（≥4爻动）则卦象不稳，提示事态纷杂，射覆中罕见，此时以卦身+大象为主

### 2. 静卦（无动爻）
- 射覆：直取**世爻**取象 + 卦身爻 + 大象卦名，三者汇聚
- 分类占：看用神旺衰、与世爻生克、月日建对用神的扶抑
- 静卦象少而纯，取象可更大胆依赖大象与卦名

### 3. 伏神启用时机
- 用神不现于明爻 → 必查伏神（伏于何爻之下、伏神旺衰、是否得出）
- 射覆中伏神常暗示"被遮盖的特征层"（如 Case-001 孙巳火伏于子水下——玩具之性被藏，恰应"覆"意）
- 伏神得出（月日冲飞起伏、伏神值日临月）→ 伏神信息权重上升

### 4. 月破、日破、空亡优先级
1. **动不为空破**：动爻即使空亡月破，其象仍须读取，待应期论破
2. 真空（春土夏金秋三木冬火）→ 该爻之象为"虚象"，提示此特征不显著或已失
3. 空亡的正面取象：**中空、内虚、藏而不露**（如打火机亥水空=燃料内藏无形）——空亡不只是"无力"，本身即是象
4. 月破日破：象"破损、不完整"，物品向提示旧损之物

## 二、卦盘录入标准模板

用户发截图时我自行读取；若用户愿意提供文字，推荐此模板（截图+模板双保险防误读）：

```
【问事】（必填，用于分类路由）
【时间】年月日时干支（含节气）
【本卦】→【变卦】（含宫、世应）
【动爻】第X爻：六亲+地支五行+纳音+六神，化出六亲地支
【空亡】【神煞】（卦身/驿马/桃花/日禄）
【伏神】（如有）
【候选】（射覆必填）
```

我接到截图后，先按此模板**复述确认卦盘信息**再断卦——发现歧义（动爻不清、六亲难辨）必须先问，不得猜测硬断。

## 三、梅花易数交叉验证（可选开关）

- 默认**关闭**；以下情况建议开启并告知用户：①多象汇聚出现平票；②置信度低于 60%；③用户明确要求
- 方法：以卦起梅花体用（或以问事时间/外应起卦），比较两法结论
- 裁决：两法同向 → 置信度上调一档；两法相背 → 如实告知用户两种答案及各自依据，请用户开覆后双重复盘（一次反馈可入两法案例）
- 典籍：仙易俏梅花、韩海军梅花心易、梅花易数实战宝录（均在项目文件夹）

## 四、规则入库冲突检测（新规则入库前"三查"）

1. **查矛盾**：新规则与既有规则是否直接冲突？冲突时不得简单并列——必须写明适用边界（何时用旧、何时用新），或标注废止旧规则
2. **查过拟合**：此规则是否仅由 1 个案例支撑且表述过窄？过窄规则降级为"观察假设"（标注【假设】），需第 2 个案例验证后转正
3. **查优先级**：新规则是否声称高优先级？优先级变动必须在总索引登记并说明理由

## 五、近事断验附加段（所有断卦必加）

**规则**：任何断卦（射覆、失物及所有分类），除回答本问之外，必须附带一段"近事断验"——
从卦中顺带读取与所问无关的近期信号，作为附加占验。

**取象来源**（附断专用，勿与本问用神混淆）：
1. **朱雀临动/临世** → 近 1–3 日有音讯、言语之事
2. **财爻动化进神/日辰合动爻** → 财物、饮食、女性缘相关的走动
3. **官鬼两现或多现** → 近有忧虑牵挂之事，临白虎防急躁小疾，临青龙为正式事务
4. **父母旺动** → 文书、学习、房屋车辆方面的动静
5. **游魂/归魂卦** → 游魂主外出变动中遇合，归魂主事将收口回巢
6. **五行偏战**（如金旺克木） → 健康提示（金克木=头面筋骨呼吸道；余类推）
7. **应期取法**：动爻值日/逢合日、空亡出空/冲空日、用神逢冲逢值日，取最近者

**纪律**：
- 附断与本问断语**分段标明**，注明"此为附断，置信度低于本问"
- 附断同样列入验证：用户反馈时本问与附断**分别记分**
- 附断不得喧宾夺主：本问优先，附断控制在 2–4 条

## 六、案例库更新操作纪律

1. **更新前必备份**：将拟改文件复制到 `/mnt/agents/upload/六爻案例库/备份/`，文件名加日期后缀（如 `射覆案例库_20260812.md`）；同日多次修改只保留当日报首次快照
2. 更新后同步总索引统计（案例数、规则数、准确率）
3. 每次断卦反馈完成后，向用户简报：案例编号、新增/修改规则、当前准确率
