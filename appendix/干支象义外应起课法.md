# 干支象义外应起课法（v1.0）

> 用途：用户叙述一件刚发生的具体事情（外应），直接起课解课、占验近事。
> 来源：贺云飞《干支易象学》（壬戌柱叠象法、触类为象、合之会意、淳于智物象起卦法）+ 梅花体用法。
> 触发信号：用户描述一段亲历事件（"刚才……""路上看到……""突然……"），或明说"按干支象义起一课/起一卦"。
> 出处案例：Case-003（白蝶入发）

---

## 一、起课总流程（五步）

### 第一步：排时空干支盘
- 取事件发生的准确时间（无则取用户叙述时间），排出年月日时四柱干支
- 先读时空盘本身的信息：月令日辰类象往往已点出场景（如申=道路车行、午=桃花花丛）

### 第二步：外应转干支（叠象成柱 · 壬戌法）
按"上/外/先见者为干，下/内/承托者为支"叠成一柱或数柱：

**颜色→天干**：白=庚辛（精美白为辛）、黑=壬癸（点斑为癸）、红=丙丁、青绿=甲乙、黄=戊己
**形态→地支**：圆润流动=子亥；长直=寅；细软纤维=卯；方厚=丑辰未戌；金属方棱=申酉；尖形发光=巳；华丽光明=午
**质地修正**：精美细小→阴干（乙辛癸丁己）；粗大刚硬→阳干（甲庚壬丙戊）
**特殊象**：癸=天网=网状斑纹；辛="辛者新也"=新事物之使；申=道路传送=车行之象

- 叠柱后读柱内关系：干生支/支生干=特征天然相生（如辛生癸=斑生于翼）；干支相克=内含矛盾

### 第三步：事件过程演绎
- 将事件动作转成干支关系：**相遇=同气相求；滞留不出=伏吟/合住；解开散去=逢冲则散**
- 伏吟、冲、合、刑是演绎"过程"的核心工具

### 第四步：物象起卦（淳于智法）
- **外来者/在上者→上卦，自身/在下者→下卦**，合成重卦
- **动爻取法**：事件的关键动作发生在什么部位/环节→取对应爻位（没于顶=上爻；缠于中=三四爻；触于足=初爻）
- 得本卦+变卦后：**装六爻**（纳甲、六亲、世应、六兽按日起、空亡按日旬）+ **定梅花体用**（动爻所在为用卦，另一为体卦）

### 第五步：合之会意断验
- 寓意层：象意直读（外应即讯息）
- 占验层：六爻法（世应、动爻、用神旺衰）+ 梅花法（体用生克、互卦、变卦）双轨互证
- **必须输出可验证的近期断语 + 明确应期**（见《通用断卦细则》第六节近事断验段）

## 二、卦象转换速查（物象→八卦）

| 卦 | 物象关键词 |
|---|---|
| 乾 | 天、圆硬、贵重、老者、权威、金属大件 |
| 兑 | 白、金、悦、少女、轻盈美好、有口之物 |
| 离 | 火、红、光明、中空、文书、丽物 |
| 震 | 动、响、长男、木、足、突发 |
| 巽 | 风、发、长软、绳、进退不果、反复 |
| 坎 | 水、黑、弯曲、险、中虚、耳 |
| 艮 | 山、止、手、块状、少男、门径 |
| 坤 | 地、布、软、众、老妇、腹、杂色 |

## 三、输出格式

1. 时空干支盘 + 场景直读
2. 外应转干支表（叠柱及柱内关系）
3. 事件过程演绎（伏吟/冲合）
4. 物象起卦：本卦→动爻→变卦 + 六爻排盘表 + 梅花体用
5. 双轨解读（六爻 / 梅花）
6. **近事断验表**（断语 + 应期 + 置信度）
7. 入库（归"其他/干支象义外应"待建类）+ 请求反馈

## 四、纪律

- 外应课**必须有可验证断语**，不许只讲寓意——否则无法复盘进化
- 验证窗口一般不超过 7 日；应验补记成功，不灵执行复盘四件套
